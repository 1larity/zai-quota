# Security

Do not post credentials, OAuth tokens, account responses or private workspace
files in issues. Report sensitive findings privately through the author's
[GitHub profile](https://github.com/1larity), using a private contact channel
listed there; if none is available, open a minimal issue requesting one without
vulnerability details. No security-response SLA or support guarantee is offered.

Only the latest release is maintained. Review the README's privacy and trust
boundaries before installing. No audit can guarantee the absence of defects.
